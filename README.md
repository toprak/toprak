### 🚀 Featured Projects

* **[🏎️ F1 Istanbul Ticket Platform](https://github.com/toprak/f1-ticket-platform)**  
  Containerized full-stack ticket sales platform simulating F1 returning to Turkey. Built with **Angular 17**, **Spring Boot**, **PostgreSQL**, **Docker Compose**, dynamic PDF ticket generation with QR codes, and custom interactive UI audio/celebration effects.

* **[🎟️ EventSphere](https://github.com/toprak/EventSphere)**  
  Full-stack event and customer management system featuring an **Angular 21 (Zoneless)** Glassmorphism interface, backed by **Spring Boot** and relational PostgreSQL entity management.

* **[🎫 BiletApp](https://github.com/toprak/BiletApp)**  
  Complete event and ticket e-commerce system built with **ASP.NET Core MVC (.NET 8)**, **Entity Framework Core**, dynamic AJAX ticket selection, CSRF validation, and automated SQLite seed data initialization.

* **[🏥 Hospital Readmission Risk Prediction](https://github.com/toprak/hospital-readmission-prediction)**  
  End-to-end Machine Learning pipeline utilizing **XGBoost** and **SMOTE** for patient 30-day readmission risk classification, served via an interactive **Streamlit** clinical interface.
